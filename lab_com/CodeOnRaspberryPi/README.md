This is the readme for the code that runs directly on the raspberry PI and machines controlled by the raspbery PI


lab_com_gui.py: Copy this code over to the raspberry PI and run it. It runs the Job fetch service, job execution service, and GUI on the RPI

led_arduino.ino: This is temporary code to test the UART over USB between the RPI and the arduino. This will eventually enable control of 
                    the spincoater arduino from the RPI.
